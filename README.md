# Інформаційно-експертна система

Практичні роботи з дисципліни **«Інтелектуальні інформаційні технології» (ІІТ)** / модуль **«Системи підтримки прийняття рішень» (СПР)**.

Програмний комплекс реалізує повний цикл навчання та екзамену системи розпізнавання образів на базі **інформаційно-екстремальної інтелектуальної технології (ІЕІТ)**.

---

## 🛠 Стек технологій та особливості реалізації

- **Мова програмування:** C# (.NET 10.0)
- **UI Framework:** WPF (Windows Presentation Foundation)
- **Архітектурний патерн:** MVVM (Model-View-ViewModel)
- **Принцип автономності:** використано **виключно стандартні бібліотеки .NET** (`System.Windows.Media.Imaging`, `System.Data`, `Microsoft.Win32`, `System.IO`) без зовнішніх сторонніх NuGet-пакетів.
- **Дизайн інтерфейсу:**
  - Сучасна табова навігація з плавними заокругленими вкладками.
  - Мінімалістичні однотонні векторні іконки високої чіткості (SVG `Geometry` + `Path`).
  - Віртуалізований `DataGrid` для плавного інспектування матриць довільної розмірності.

## 🚀 Вимоги та запуск

1. **Вимоги:**
   - Встановлений **.NET 10.0 SDK** (або .NET 8.0/9.0 з підтримкою `net10.0-windows`).
   - ОС: Windows 10 / Windows 11.

2. **Збірка проєкту:**
   ```bash
   dotnet build
   ```

3. **Запуск додатку:**
   ```bash
   dotnet run
   ```
