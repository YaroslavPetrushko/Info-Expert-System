# Інформаційно-експертна система розпізнавання образів

Практичні роботи з дисципліни **«Інтелектуальні інформаційні технології» (ІІТ)** / модуль **«Системи підтримки прийняття рішень» (СПР)**.

Програмний комплекс реалізує повний цикл навчання та екзамену системи розпізнавання образів на базі **інформаційно-екстремальної інтелектуальної технології (ІЕІТ)**.

---

## 🛠 Стек технологій та особливості реалізації

- **Мова програмування:** C# (.NET 10.0)
- **UI Framework:** WPF (Windows Presentation Foundation)
- **Архітектурний патерн:** MVVM (Model-View-ViewModel)
- **Принцип автономності:** використано **виключно стандартні бібліотеки .NET** (`System.Windows.Media.Imaging`, `System.Data`, `Microsoft.Win32`, `System.IO`) без зовнішніх сторонніх NuGet-пакетів.
- **Дизайн інтерфейсу:**
  - Сучасна табова навігація з заокругленими вкладками в єдиному корпоративному стилі.
  - Мінімалістичні однотонні векторні іконки високої чіткості (SVG `Geometry` + `Path`).
  - Високопродуктивний компонент `FastDataGrid` із повною віртуалізацією рядків і стовпчиків для плавного відображення матриць великої розмірності.
  - Динамічний рендеринг графіків на `Canvas` та бітових растрових карт (`WriteableBitmap`).

### ✅ Лабораторна робота № 13: «Формування бінарної навчальної матриці та бінарних еталонних векторів» (Виконано)
- [x] **Вибір базового класу розпізнавання ($x_{base}$):** інтерактивний вибір класу з найвищою функціональною ефективністю («Норма», за замовчуванням Клас 1).
- [x] **Розрахунок системи контрольних допусків (СКД):**
  - Обчислення вектора математичних сподівань ознак базового класу $M[y_i^{(base)}] = \frac{1}{l} \sum_{j=1}^l y_{ji}^{(base)}$.
  - Розрахунок нижніх ($ND_i = M[y_i] - \delta$) та верхніх ($VD_i = M[y_i] + \delta$) допусків з регульованим кроком $\delta \in [0, 255]$ (числове поле + повзунок).
- [x] **Бінаризація 3D-навчальної матриці ($Y \to X$):** покомпонентне квантування яскравості у двійкові коди ($0$ або $1$) за умовою потрапляння в допусковий коридор $[ND_i, VD_i]$ для всіх класів алфавіту розпізнавання.
- [x] **Синтез двійкових еталонних векторів ($EV$):** побудова бінарних геометричних центрів класів за строгим правилом більшості ($\frac{1}{l}\sum_{j=1}^l x_{ji}^{(m)} > 0.5$).
- [x] **Графік допускового коридору СКД:** векторна візуалізація на базі `Canvas` та `Polyline` з кривими $MeanVector$, $ND$, $VD$, сіткою значень $[0..255]$, розміткою осі ознак $1..N$ та колірною легендою.
- [x] **Інспектор двійкової матриці $X$:** віртуалізована таблиця `FastDataGrid` для перегляду зрізів $X$ за обраним класом поруч із масштабованою растровою піксельною картою образу ($100 \times 100$ px, 1=чорне, 0=біле).
- [x] **Візуалізація еталонних векторів $EV$:** картки класів із генерацією контрастних штрих-кодів (`BarcodeImage`) та лічильником активних одиниць.
- [x] **Кількісні характеристики бінаризації:** табличний розподіл кількості та відсотка одиниць у бінарних матрицях $X$ для кожного класу.
- [x] **Синхронізація та надійність:** автоматичне скидання стану бінаризації при зміні даних на Вкладці 1, блокування запуску до формування матриці $Y$, миттєве оновлення інспектора та реактивне відображення параметрів $m$ та $l \times N$.

### ✅ Лабораторна робота № 14: «Формування масиву кодових відстаней від центрів класів до їх реалізацій» (Виконано)
- [x] **Визначення взаємно найближчих класів-конкурентів ($PARA$):** знаходження найближчого сусіда в просторі Хеммінга $PARA[m] = \arg\min_{k \ne m} d_H(EV^{(m)}, EV^{(k)})$ та розрахунок міжеталонної кодової відстані $D$.
- [x] **Формування тривимірних масивів кодових відстаней ($SK$ та $SK\_PARA$):**
  - Масив $SK[M][2][L]$: кодові відстані від власного геометричного центру до власних реалізацій ($SK[m][0][j]$) та до реалізацій найближчого сусіда ($SK[m][1][j]$).
  - Масив $SK\_PARA[M][2][L]$: кодові відстані від геометричного центру найближчого сусіда до його власних реалізацій ($SK\_PARA[m][0][j]$) та до реалізацій поточного класу ($SK\_PARA[m][1][j]$).
- [x] **Підтримка довільних розмірностей ($l \ne N$):** коректна робота алгоритмів та інспектора для прямокутних зрізів, де кількість рядків у масивах відстаней строго дорівнює $l$.
- [x] **Модуль геометричної 2D-візуалізації $SK\_MAP$:**
  - Розташування центрів на осі: $C_1(0, 0)$ та $C_2(D, 0)$.
  - Аналітична триангуляція перетину двох кіл: $x = \frac{D^2 + r_1^2 - r_2^2}{2D}$, $|y| = \sqrt{\max(0, r_1^2 - x^2)}$.
  - Математичне обґрунтування невід'ємності підкореневого виразу на базі аксіоми нерівності трикутника для метрики Хеммінга.
  - Детерміноване знакове чергування $y = \text{sign}(j) \cdot |y|$ за парністю індексу $j$ для усунення стохастичності та досягнення абсолютної повторюваності.
  - Захист від ділення на нуль при збігу еталонів ($D=0$) із блокуванням графіка та виведенням попереджувального банера.
  - Єдиний ізотропний масштаб (1:1) за осями X та Y для збереження кругової геометрії контейнерів у ЛР №15.
  - Візуальні маркери центрів, пунктирна вісь, кольорове кодування точок кластерів, групування перекриттів та спливаючі підказки (Tooltip).
- [x] **Табличний інспектор $SK$ та $SK\_PARA$:** віртуалізований `FastDataGrid` для перегляду відстаней обраного класу за кожною реалізацією.
- [x] **Статистична картка розподілу:** розрахунок показників Min, Max та Середнє значення для всіх зрізів відстаней.
- [x] **Повна архітектурна синхронізація:** реактивне скидання результатів Вкладки 3 при зміні вхідних даних на Вкладках 1 або 2.

## 🚀 Вимоги та запуск

1. **Вимоги:**
   - Встановлений **.NET 10.0 SDK** (або .NET 8.0/9.0 з підтримкою `net10.0-windows`).
   - ОC: Windows 10 / Windows 11.

2. **Збірка проєкту:**
   ```bash
   dotnet build
   ```

3. **Запуск додатку:**
   ```bash
   dotnet run
   ```
